**Scope**: This document schedules later local implementation; generating it does not execute any task. Stay on the current branch. Do not write tests merely to assert source strings, filenames or coverage counts.

**Local boundary**: No training, GPU execution, weight/tokenizer downloads, package builds, server transfer or server verification is a task here. Use an already available compatible CPU environment and the offline settings in `quickstart.md`. Do not install dependencies as an incidental workaround. Small tensor, optimizer/scheduler and Accelerator serialization unit checks are permitted; invoking the training loop or simulating an entire run is not. Real dependencies and readers must not be replaced by fake modules to manufacture a pass.

**Evidence**: During implementation, create `specs/001-scope-qwen-image-lora/validation.md` for the baseline, exact reviewed removal inventory, commands, results, limitations and requirement-to-evidence mapping. It is not created by this tasks-generation step. Record missing prerequisites as unavailable. Required unavailable evidence keeps its task/gate incomplete; source-only checks do not satisfy real parser/import/serialization requirements. Record the absence of external runs once in the final results section.

## Format and Path Conventions

- Tasks use `- [ ] Tnnn [P?] [USn?] Description` and carry requirements, dependencies and an observable result.
- Paths are relative to the repository root. A directory in a removal task means only the reviewed source files recorded in the inventory, never user data or a wildcard deletion rule.
- `[P]` means the task can run alongside the named sibling after their prerequisites pass, with disjoint edited files. Shared test/evidence files are prepared or consolidated separately.
- FR and SC references resolve to `spec.md`; entity/format constraints resolve to `data-model.md`. Constitution principles apply throughout.
- Apply the consumer-first rule to symbols as well as modules: update a retained caller/import before dropping a shared constant, export, parameter or class. During US1, keep only the transitional symbols still imported by the not-yet-adapted Qwen trainer/metadata/cache consumers, list them in the inventory, and remove them after T015/T016/T022/T023/T024, with the final sweep in T039. Do not create compatibility shims or copy excluded implementations to accomplish this.
