# Тренер обучения LoRA для Qwen-Image

Инструмент создан на базе [Musubi Tuner](https://github.com/kohya-ss/musubi-tuner) для обучения LoRA на Qwen-Image original.

## Основные изменения

- **Репозиторий ограничен целевым workflow.** Удалены реализации других моделей, full finetuning, видеообучение, Qwen-Image Edit/Layered и отдельные инструменты инференса. Сохранены подготовка изображений с подписями, кэширование, обучение, контрольные изображения, логирование и применимые настройки оптимизации памяти.

- **Добавлено автоматическое кэширование train- и val-датасетов.** При `auto_cache=true` запуск обучения проверяет кэши латентов и текстовых эмбеддингов, создаёт недостающие файлы и повторно использует корректные. Устаревшие или повреждённые файлы вызывают ошибку с пояснением причины. Автокэширование работает при `experiment_mode=true` в одном процессе; ручные команды кэширования также сохранены.

- **Добавлена валидация на фиксированном шуме.** Для каждого изображения отдельного val-датасета используются одни и те же уровни шума и его реализации: их задают `val_seed_noise`, `val_level_noise_n` и `val_seed_noise_n`. В готовом конфиге это 10 уровней и 2 реализации на уровень. Валидация использует ту же функцию loss, что и обучение, но не обновляет веса; dropout временно отключается, состояния генераторов случайных чисел восстанавливаются после проверки.

- **Val-loss разделён на три метрики в TensorBoard.** `val_loss_mean` показывает среднее по всем уровням, `val_loss_low_noise` — по нижней половине уровней шума, `val_loss_high_noise` — по верхней. Каждое изображение имеет одинаковый вес в среднем. Метрики записываются до первого обновления весов, через `val_every_n_steps` завершённых шагов оптимизатора и на последнем шаге, что позволяет сравнивать чекпоинты по общей ошибке и двум диапазонам шума.

- **Результаты сгруппированы по шагам обучения.** В режиме `experiment_mode` каждый чекпоинт получает папку `output/<output_name>-step<шаг>/`: в ней находятся веса `model.safetensors`, состояние для продолжения обучения при включённом сохранении и контрольные изображения в `samples/`. Логи TensorBoard в готовом конфиге находятся в `output/tensorboard`. Относительные пути считаются от соответствующего TOML-файла, поэтому папку эксперимента можно копировать под новым именем.

- **В готовом конфиге включено сохранение полного состояния.** `save_state=true` сохраняет не только LoRA, но и состояние оптимизатора, планировщика, генераторов случайных чисел и номер завершённого шага. При `resume` в режиме эксперимента продолжаются счётчик шагов и тот же запуск TensorBoard; `max_train_steps` задаёт общую цель, а не число дополнительных шагов. Для такого чекпоинта используется `save_precision="fp32"`, чтобы единственная копия обучаемых весов не теряла точность при сохранении.

- **Убрано дублирование весов в чекпоинтах эксперимента.** В папке шага хранится одна копия адаптера, используемая и для экспорта, и для восстановления состояния. Если периодическое и финальное сохранения приходятся на один шаг, второй комплект весов не создаётся. Сроки хранения весов и состояния настраиваются отдельно; очистка старых чекпоинтов сохраняет контрольные изображения.

- **Добавлены проверки входных данных и конфигурации.** Неизвестные параметры, неподдерживаемые режимы и некорректные сочетания настроек отклоняются до загрузки модели. Train- и val-датасеты проверяются на пересечение по содержимому изображений, а при продолжении валидации проверяется совместимость её данных, кэшей и настроек с сохранённым состоянием.

## Быстрый старт

1. Сделайте дубликат папки `config_for_qwen_image_lora` с `<новое_имя_папки>`
2. Добавьте изображения с подписями в `<новое_имя_папки>/dataset/train` и `<новое_имя_папки>/dataset/val`. Наборы не должны содержать одинаковые изображения.
3. В [train.toml](config_for_qwen_image_lora/train.toml) скопированной папки задайте пути к моделям, число шагов и другие параметры обучения.
4. В `train-dataset.toml` и `val-dataset.toml` укажите датасеты и каталоги кэша. В `train-dataset.toml` задайте `batch_size` согласно доступной VRAM вашего GPU; для val оставьте `batch_size=1` и `num_repeats=1`.
5. Запустите обучение из корня репозитория:

```bash
python qwen_image_train_network.py --config_file <новое_имя_папки>/train.toml
```

## Примечания

1. В готовом конфиге автокэширование включено: перед обучением скрипт проверит кэши указанных датасетов и создаст отсутствующие. Если кэши устарели или повреждены, запуск остановится с объяснением причины.
2. Для продолжения обучения из сохранённого состояния используйте исходные датасеты, кэши и совместимые настройки валидации. Параметр `resume` должен указывать на папку полного чекпоинта, а не на отдельный файл LoRA.
