## Детерминированный val-loss + разбивка по уровням шума

### Валидационные датасеты
- Пользователь самостоятельно подготавливает два непустых датасета:
	- `val_familiar` — знакомые изображения, участвующие в обучении
	- `val_unfamiliar` — незнакомые изображения, не участвующие в обучении
- Оба датасета полностью зафиксированы на протяжении обучения 
- Автоматические изменения входа валидации запрещены 
- `id_изображения` должен сохраняться между запусками и не зависеть от порядка загрузки

### Периодичность и режим выполнения
- Валидация выполняется:
	- До первого обновления весов — шаг 0
	- После каждых `val_every_n_steps` завершённых шагов оптимизатора, после накопления градиентов и до начала следующего обучающего шага
	- После последнего шага обучения. Если он совпадает с периодической валидацией, повторная проверка не выполняется
- `val_every_n_steps` — целое число ≥ 1. На графиках используется количество завершённых шагов оптимизатора
- Размер батча при валидации всегда равен 1. Dropout отключается; после валидации восстанавливаются режим обучения и dropout
- Валидация не влияет на обучение: выполняется без расчёта градиентов, обновления весов и изменения состояния оптимизатора 
- Для шума используется отдельный генератор случайных чисел, не меняющий последовательность случайностей обучения

#### Детерминированный шум
| Параметр            | Назначение                                       |
| ------------------- | ------------------------------------------------ |
| `val_seed_noise`    | Общий seed для валидационных датасетов           |
| `val_level_noise_n` | Число уровней шума `N1`: чётное, ≥ 2             |
| `val_seed_noise_n`  | Число реализаций шума на каждом уровне `N2`: ≥ 1 |

- Для каждого изображения из обоих датасетов выполняется `N1 × N2` проверок
- Диапазон `0.05–0.95` делится на `N1` равных интервалов
- Уровень шума каждого интервала — его середина.
-Уровни разделяются на две группы:
	- `low noise`: `0.05 ≤ t < 0.5`
	- `high noise`: `0.5 ≤ t ≤ 0.95`
- Значения `0.05–0.95` — конечные коэффициенты смешивания изображения с шумо. 
- При передаче timestep в интерфейс тренера со шкалой `0–1000` они умножаются на 1000
- shift повторно не применяется
- Seed каждой проверки вычисляется детерминированно через условную функцию `stable_hash` на основе `hashlib.sha256`:
- `seed = stable_hash(val_seed_noise, SHA-256 содержимого файла, i, j)` — здесь `i` — номер уровня шума от 1 до `N1`, `j` — номер реализации шума на этом уровне от 1 до `N2`.
- Проверяются ограничения параметров и непустота обоих датасетов

### Расчёт и усреднение loss
- Расчёт выполняется отдельно для `val_familiar` и `val_unfamiliar`:
	- Для каждой проверки используется тот же способ расчёта ошибки, что и при обучении
	- Для каждого изображения усредняются ошибки всех `N1 × N2` проверок, затем полученные значения усредняются по изображениям датасета 
	- Результат записывается в `loss_mean`
	- `loss_low_noise` и `loss_high_noise` рассчитываются аналогично, только по проверкам соответствующей группы уровней шума

### Графики в TensorBoard
К уже реализованным графикам loss в тренере должны отображаются дополнительных 6 графиков val-loss:
| График                                                             | Содержание                                                    |
| ------------------------------------------------------------------ | ------------------------------------------------------------- |
| `train_eval_loss_mean`                                             | Loss на `val_familiar`, усреднённый по шумам и изображениям   |
| `train_eval_loss_low_noise`                                        | Loss на `val_familiar` для `low noise`                        |
| `train_eval_loss_high_noise`                                       | Loss на `val_familiar` для `high noise`                       |
| `val_loss_mean`                                                    | Loss на `val_unfamiliar`, усреднённый по шумам и изображениям |
| `val_loss_low_noise`                                               | Loss на `val_unfamiliar` для `low noise`                      |
| `val_loss_high_noise`                                              | Loss на `val_unfamiliar` для `high noise`                     |

При запуске обучения, с учётом сохранённого оптимизатор(resume), loss и val-loss графики должны начинать строиться с того шага, на котором был сохранён оптимизатор
